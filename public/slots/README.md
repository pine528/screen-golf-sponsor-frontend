# 착장 슬롯 이미지

여기에 파일을 넣으면 경매 상세의 "슬롯 위치" 표시가 벡터 도형 대신 이 이미지를 사용합니다.
파일이 없으면 자동으로 기존 도형으로 대체되므로 하나씩 채워 넣어도 됩니다.

## 파일명
- `cap-front.png`  모자 정면
- `cap-side.png`   모자 측면
- `cap-back.png`   모자 뒷면
- `top-front.png`  상의 정면
- `top-back.png`   상의 뒷면
- `pants.png`      하의

## 이미지 조건
- 정사각형(1:1), 1000×1000px 이상
- 배경 투명(PNG) — 화면 배경색과 자연스럽게 어울리게 하기 위함
- 무지 제품(로고·문구 없음) — 슬롯 위치 표시가 겹치지 않도록
- 밝은 회색/흰색 계열 권장 (초록 점선 표시가 잘 보임)
- 정면/측면/뒷면의 촬영 각도와 조명을 통일

파일을 넣은 뒤 `src/pages/AuctionDetail.tsx`의 `SLOT_IMAGES`에 경로를 등록하면 적용됩니다.

# 착장 슬롯 이미지

여기에 파일을 넣으면 경매 상세의 "슬롯 위치" 표시가 벡터 도형 대신 이 이미지를 사용합니다.
파일이 없으면 자동으로 기존 도형으로 대체되므로 하나씩 채워 넣어도 됩니다.

## 필요한 파일과 담당 슬롯

| 파일명 | 뷰 | 이 이미지로 표시되는 슬롯 |
|---|---|---|
| `cap-front.png` | 모자 정면 | 모자 정면, 모자챙 상단 |
| `cap-side.png` | 모자 측면 | 모자 좌측면, 모자 우측면 |
| `cap-back.png` | 모자 뒷면 | 모자 뒤 |
| `top-front.png` | 상의 정면 | 상의 좌/우측, 카라 좌/우, 소매 좌/우, 어깨라인 좌/우 |
| `top-back.png` | 상의 뒷면 | 등 어깨 상단 좌/우 |
| `pants-side.png` | 하의 측면 | 하의 엉덩이 옆라인, 하의 허벅지 옆라인 |

## 공통 조건 (6장 모두 동일하게)

- 정사각형 1:1, 1000×1000px 이상
- **배경 투명 PNG**
- **무지 제품** — 로고·브랜드명·글자·패턴 없음 (슬롯 표시가 겹치지 않도록)
- 밝은 회색~흰색 계열 (초록 점선 표시가 잘 보임)
- 정면을 향한 평면적 구도, 제품 주변에 여백을 조금 남길 것
- 6장 모두 같은 조명·같은 각도·같은 색상

## ChatGPT 프롬프트

### 공통 스타일 문구 — 매 요청 끝에 붙이기

```
스타일: 부드러운 그림자와 은은한 음영이 있는 깔끔한 제품 목업 렌더.
배경 완전 투명(PNG), 정사각형 1000x1000, 제품 주변 여백 약간.
로고·글자·패턴 없는 무지 제품, 밝은 회색~흰색 계열.
```

### 1. 모자 정면 — `cap-front.png`
```
골프 볼캡을 정면에서 본 제품 목업 이미지를 만들어줘.
크라운(앞판)과 챙이 모두 보이고, 좌우 대칭으로 똑바로 정면을 향할 것.
```

### 2. 모자 측면 — `cap-side.png`
```
같은 골프 볼캡을 정확히 옆에서 본 모습으로 만들어줘.
챙이 오른쪽을 향하고 옆면 패널 전체가 보일 것.
앞서 만든 모자와 같은 제품·같은 색·같은 조명으로.
```

### 3. 모자 뒷면 — `cap-back.png`
```
같은 골프 볼캡을 뒤에서 본 모습으로 만들어줘.
뒷판과 사이즈 조절 밴드가 보일 것.
앞서 만든 모자와 같은 제품·같은 색·같은 조명으로.
```

### 4. 상의 정면 — `top-front.png`
```
골프 반팔 카라티(폴로 셔츠)를 정면에서 평평하게 펼쳐 놓은 제품 목업 이미지를 만들어줘.
카라, 앞단추 부분, 양쪽 소매, 어깨선이 모두 또렷하게 보이도록.
```

### 5. 상의 뒷면 — `top-back.png`
```
같은 골프 반팔 카라티의 뒷면을 평평하게 펼쳐 놓은 모습으로 만들어줘.
등판 전체와 양쪽 어깨 상단이 보일 것.
앞면 이미지와 같은 제품·같은 색·같은 조명으로.
```

### 6. 하의 측면 — `pants-side.png`
```
골프 긴바지를 옆에서 본 제품 목업 이미지를 만들어줘.
허리 밴드부터 밑단까지 한쪽 측면 라인(엉덩이 옆·허벅지 옆)이 전부 보이도록 세로로 길게.
상의와 같은 색 계열·같은 조명으로.
```

## 일관성 팁

- **한 대화창에서 6장을 연속으로** 요청하세요. 새 대화에서 만들면 색과 조명이 달라집니다.
- 2번부터는 "앞서 만든 것과 같은 제품·같은 색·같은 조명으로"를 꼭 붙이세요.
- 결과가 어두우면 "더 밝은 회색으로", 그림자가 세면 "그림자를 더 은은하게"로 다시 요청하세요.
- 배경이 흰색으로 나오면 "배경을 완전히 투명하게(알파 채널)"라고 다시 요청하세요.

## 적용 방법

파일을 이 폴더에 넣은 뒤 `src/pages/AuctionDetail.tsx`의 `SLOT_IMAGES`에 슬롯 코드별 경로를 등록하면 적용됩니다.
이미지 기준 표시 위치는 같은 파일의 `SLOT_IMAGE_MARKS`에서 조정합니다.
